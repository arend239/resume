## Resume PDFs
 - Sources and generated PDFs both live in `resume-template/template/`: `resume.typ`/`resume.pdf` (PT) and `resume-en.typ`/`resume-en.pdf` (EN).
 - The site links directly to those PDFs, so there's a single copy of each file.
 - To update: edit the `.typ` file and run `typst compile resume-template/template/<file>.typ` — the PDF is regenerated in place and picked up by the site automatically.
 - `resume-en-legacy.typ`/`resume-en-legacy.pdf` is the previous EN resume, kept for reference only — not linked from the site.
